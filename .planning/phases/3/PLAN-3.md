# Phase 3: Windows upgrade install - Plan 3: The upgraded app registers its tray icon on Arm64 too

## Goal

Installing a new version over an existing one leaves an app that starts cleanly: after the upgrade over v1.20.1 it shows its tray icon and no "Unhandled exception in script" dialog on both x64 and Arm64 PCs, and `smoke-windows` checks exactly that rather than a proxy for it.

- The broken-tray control from 3f47ab27 still runs in step 8 on both installer rows and passes only on a rejection that names "Unhandled exception in script" (UAT item 7, dialog half).

- `smoke.sh` carries no NotifyIconSettings read (b96a5a7f reverted), and neither `release.yml` nor `scripts/probes/` carries the Task 2 probe on the phase's last commit.

### Task 2: A CI probe of the app's tray registration on both architectures, run on an owner push

The probe builds the icon with the app's own `hqptuner.desktop.pystray_icon` (no-op Open and Quit callbacks), so the image, name, title and menu are the app's. It runs that icon with `Icon.run`, passing a setup callback that does what pystray's default setup does, `icon.visible = True`, and records any exception raised there. It records every `Shell_NotifyIconW` call pystray makes while the icon runs: the `NIM_*` code, `uFlags`, `hWnd`, `uID`, `cbSize` and the return value. Read the record knowing that the first call is `_update_icon`'s `NIM_MODIFY`, expected to return 0 on both rows. A recording wrapper on `pystray._util.win32.Shell_NotifyIcon` that calls the original sees every call, since `_message` looks it up at call time. It records the interpreter's `platform.machine()`, pointer size, `sys.version`, and the pystray and Pillow versions. It records `ctypes.sizeof` and each field offset of pystray's `NOTIFYICONDATAW` beside the documented 64-bit values in Context. Then, with no icon registered for that window and uID 0 (when pystray's add succeeded, delete it first with a `NIM_DELETE` of pystray's own structure, recorded), it makes one add carrying exactly the values pystray's add carried (window, uID 0, flags, callback message, icon handle, tip) in a 976-byte buffer filled at the documented offsets by arithmetic, independent of ctypes' structure layout, and records its return value. It then deletes that icon with the same buffer, records the delete, and stops the pystray icon. It prints the byte ranges where pystray's structure for the add and the documented buffer differ, by field name. Constraints: the probe makes no call to find, enumerate or query any shell window or process, reads no registry key, and makes no `Shell_NotifyIconGetRect` call; its only shell32 calls are the notify adds and deletes the app's own tray path makes (owner ruling).
