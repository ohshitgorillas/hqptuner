## Decisions

- D-08 (Escaping): every value HQPTuner writes into `hqplayerd.xml` is XML-escaped (`set_attr`, `fixedvol`'s level and comment, `_route`'s device), and `get_attr` unescapes on read, so a value with `&` or `'` still verifies; the escape helper lives at or below `xmledit` so no layering cycle forms. Evidence: `hqptuner/conf/xmledit.py:174-198`, `hqptuner/conf/fixedvol.py:109-124`, `hqptuner/conf/presetconf.py:204-213`, `hqptuner/conf/matrixscope.py:44-55`.
- D-09 (F-019): the whitespace-leading patterns `matrixprofiles._profile_re`, `matrixconf.py:140`, `matrixconf.py:177`, `fixedvol._COMMENTED_FIXED_RE` and `xmledit.drop_attr` are anchored, and staged values carry a ceiling on value length and key count on the stage and live-held paths. The ceiling test is the proof that fails against the pre-fix code; the anchoring is held by characterization cases, the precedent of phase 6's `5b73a1e3`. Evidence: `hqptuner/conf/matrixprofiles.py:49-60`, `hqptuner/conf/fixedvol.py:27`, `hqptuner/conf/xmledit.py:201-203`, `hqptuner/api/models.py:20-30`, `docs/testing.md` rule 7.
- D-10 (F-016): `POST /api/restore` refuses an upload larger than `BACKUP_CEILING` plus headroom for the descriptions member, and checks each member's declared decompressed size and the total against a ceiling before reading; `snapshot_members` gets the same check. Real backups on this host measure about 8.7 MB compressed, 10.7 MB decompressed, largest member 2.36 MB. Evidence: `hqptuner/api/routes/config.py:315-351`, `hqptuner/conf/presetzip.py:162-196`, `hqptuner/conf/httpconf.py:120-128`, `hqptuner/api/routes/matrix/matrix.py:276-281`.
- D-11 (F-007 members): an archive with a member name that is absolute, contains `..`, contains a backslash or carries a drive prefix is refused; at the archive root only the working-config XML (`hqplayerd.xml`, or `<Profile>.xml` when a named preset is active) is allowed. This is an observed-member rule; HQPlayer's docs do not document the format. Evidence: member listing of two backups on this host, `docs/protocol.md:88-92`, `hqptuner/conf/engineconf.py:151-190`.
- D-12 (F-032): description entries carried by an archive pass the same `_validate_name` and `_validate_text` as `PUT`; a failing entry is dropped and logged, and the rest merge. Evidence: `hqptuner/presets/store/descriptions.py:196-235,293-309`.
- D-13 (F-010): `ControlClient.send` escapes every attribute value it sends (engine importing `conf.matrixscope.attr_escape` under the layering contract), and `POST /api/volume` goes through the existing number check. Evidence: `hqptuner/engine/control.py:305-345`, `hqptuner/core/applyops.py:115-132`, `hqptuner/lanes/writer.py:176-192`, `pyproject.toml` `[tool.importlinter]`.
- D-14 (F-014): a matrix profile switch re-reads `MatrixListProfiles` and refuses a name absent from it, compared in the decoded form `get_matrix_profiles` returns; the empty name (`[Default]`) is always allowed; the refusal is owner copy. Evidence: `hqptuner/api/routes/matrix/matrix.py:111-193`, `hqptuner/lanes/matrixlane.py:36-42`, `docs/matrix-spec.md:131,184`.
- D-15 (F-026): preset, snapshot and mode paths are resolved and must stay inside their store on every platform; the Windows build also refuses `:` and reserved device names, and Linux keeps accepting colon names; the Windows refusal is owner copy. Evidence: `hqptuner/presets/names.py:76-88`, `hqptuner/presets/store/presets.py:142-165`, `hqptuner/presets/store/live.py:218`, `hqptuner/presets/store/matrixmode.py:195`.
- D-16 (Record and constraints): one `.planning/security/DISPOSITIONS.md` entry per finding in the phase 4 shape; no new source module in `hqptuner/conf/`, `hqptuner/engine/`, `hqptuner/api/routes/` or `hqptuner/static/store/` (15 files each, filepawl's cap) and `engine/control.py` growth runs `filepawl accept`; new tests in `tests/api/surface`, `tests/api/login`, `tests/engine/http`, `tests/matrix` or `tests/audit`; every new parser-refusal path catches every exception type so none surfaces as a 500; every new refusal text and the `### Security` changelog entry are owner copy. Evidence: `.filepawl.toml`, `pyproject.toml:116-123`, phase 6 `a87efb10`, `CLAUDE.md` copy rule.

## Acceptance criteria

- [ ] AC1: a staged value containing `"`, `<`, `&` or `'` lands in `hqplayerd.xml` as entity text and reads back as the original value, and a Control API command carrying such a value is sent escaped
- [ ] AC2: a staged `matrix_enabled` of `on`, or any value not among its page's choices, is refused at `/api/config/stage` and at `/api/config/live` with nothing written; a 401 following a normal answer in the same apply is reported as an engine fault and `credentials_ok` is unchanged
- [ ] AC3: a restore upload over its ceiling, one with a member whose declared decompressed size is over its ceiling, and one with a member name that is absolute, contains `..` or contains a backslash are each refused with nothing sent to the daemon; an over-limit description entry in an accepted archive is dropped and the other entries merge
- [ ] AC4: a staged value over the length ceiling is refused; `/api/audit` with a `limit` over its cap answers at most the cap; a profile switch naming a profile absent from a fresh `MatrixListProfiles` read is refused and no switch command is sent
- [ ] AC5: a preset, snapshot or mode name resolving outside its store is refused on every platform; under the Windows build `a:b` and `CON` are refused while on Linux `a:b` saves; a daemon option labelled `constructor` renders in Simplified mode without error
- [ ] AC6: `.planning/security/DISPOSITIONS.md` lists all 13 findings, each fixed one naming its commit and a proof that fails against the pre-fix code and each declined or deferred one quoting the owner's ruling, and `check`, `e2e`, `smoke`, `lifecycle-deb`, `lifecycle-rpm`, `smoke-macos` and `smoke-windows` pass on the phase's last `dev` commit (ci: check, e2e, smoke, lifecycle-deb, lifecycle-rpm, smoke-macos, smoke-windows)

- hqplayerd's 4321 parser decodes `&quot;`, `&amp;` and `&apos;` in incoming attributes - Unclear (research; documented-interface behavior, provable only by an idle-gated live probe under the `live-daemon` skill); if wrong: D-13's escape turns profile names with quotes into names the daemon does not know.
- What `/restore scope=system` does with member names outside the observed set - Unclear (never probed on production); if wrong: D-11's rule is looser or stricter than the daemon needs.
- Whether Starlette's multipart parser sets any size limit before `UploadFile.read()` in the pinned version - Unclear (research); if wrong: D-10's upload ceiling sits after the memory is already spent.
- How current Windows treats reserved device names with an extension and `name:stream.xml` - Unclear (research); if wrong: D-15's Windows refusals miss or over-refuse a name.
- Whether current hqplayerd still wedges on `<matrix enabled="on">` (probed on 6.0.4 only) - Unclear; if wrong: none for D-01, which refuses the value regardless.
- The working-config XML is the only root member of a real backup, and no backup carries `hqplayerd-auth.xml` - Likely (sample of 2); if wrong: D-11 refuses a user's own backup.
- Every staged field the UI offers has its choices on the `/config` or `/matrix` page, or is free text - Likely; if wrong: D-01 refuses a valid value for a field the pages do not list.
