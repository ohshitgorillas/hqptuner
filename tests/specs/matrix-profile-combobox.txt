wire and protocol facts

- Saved profile names come from the running engine's own enumeration, served by GET /api/matrix (`hqptuner/api/routes/matrix.py`), which is the authority for names and ordering; static data joins by name (docs/architecture.md §2).
- A profile is a whole matrix context, `<post_process>` included (hqplayerd-readme.txt §1.11.2); loading one is the live 4321 lane and undisturbs playback. Nothing in this change reaches that lane.
- Descriptions are HQPTuner's own store, GET/PUT /api/descriptions, keyed by profile NAME because `<matrix_profile>` carries only `name` (hqplayerd-readme.txt §1.12) and hqplayerd's config has nowhere to hold the text.
- `[Default]` is wire data, not copy: it is the name the daemon's own page carries for the unnamed profile (tests/support/fixtures/matrix-6.0.4.html:42, served by tests/support/fake_http.py:546).
