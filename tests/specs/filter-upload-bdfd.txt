# hqptuner/presets/presetops.py
class PresetOps:
    def park_filter(self, name: str, data: bytes) -> dict[str, str]:
        """Park one uploaded filter, returning its stored name and the daemon-side path a process string should use."""
    @property
    def filter_max_bytes(self) -> int:
        """Per-file byte limit an upload must not exceed."""

# hqptuner/presets/store/filterpark.py
class FilterPark:
    def __init__(self, directory: Path, hqp_home: str) -> None:
    def park(self, name: str, data: bytes) -> dict[str, str]:
        """Store one upload. Refuses a name with path or separator characters, a body that is not a WAVE container or text, and a park at its ceiling."""

# hqptuner/config.py
class Config:
    filter_max_bytes: int  # HQPTUNER_FILTER_MAX_BYTES, default 32 MiB

Wire and protocol facts:

- Refusals answer the shared `{"detail": <sentence>, "code": "invalid_input"}` shape with status 422 (`docs/architecture.md` API errors; `hqptuner/api/errors.py` maps `invalid_input` to 422). Error text is copy; assert the code.
- A parked file is reported as `{"name": <stored name>, "path": "<hqp_home>/<stored name>"}`; the fixture pins `hqp_home` to `/x/home`.
- Parked files live at `<backup_dir>/pending-filters/<name>`; the fixtures put `backup_dir` in `tmp_path` (`tests/support/fixtures_clients.py:60-85`, `tests/conftest.py:275-303`).
- The daemon's `process` attribute is a comma-separated list where `:` and `;` introduce plugin syntax (`hqplayerd-readme.txt:824-828`), which is why a comma in a name is refused.
- HQPlayer's matrix `process` accepts a WAV impulse file or a Room EQ Wizard text export (manual, "Matrix" section); a WAV is a RIFF form of type `WAVE` with a `fmt ` and a `data` chunk.
