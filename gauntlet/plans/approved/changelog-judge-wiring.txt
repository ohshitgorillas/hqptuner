decisions I own

`scripts/gates/check_changelog.py` stays, and stays in `lint`. The judge's pattern screen restates all nine of its rules — same 75-word cap (`scripts/gates/check_changelog.py:45`, `changelog_trivia.py:78`), bold lead, second person, marketing register, narration by negation, one heading per kind in Keep a Changelog order. The redundancy is deliberate: check_changelog.py is offline and runs under `check` (`Makefile:25`, inside `lint` at `Makefile:9`); deleting it would move that enforcement onto a model call and `check` would stop being offline.

`scripts/gates/check_gates_wired.py` needs nothing. It scopes to gate scripts in `scripts/gates/` (`scripts/gates/check_gates_wired.py:1`); `triviajudge-changelog` is a console script, so it is outside that gate's reach. No exemption is involved, and none is proposed.

cost

A model call on every commit that touches CHANGELOG.md and adds a bullet. Pre-commit already pays this shape of cost for markdown at `md-trivia`. One more call at each `Stop`/`SubagentStop` that touched CHANGELOG.md, once step 0 has happened. One whole-section call per bump.

The bump's own commit costs no second call. `scripts/bump.sh:119-128` commits through ordinary pre-commit, so the new hook fires there, but the only lines that commit adds to CHANGELOG.md are the `## [<version>] — <date>` heading and a blank line (`scripts/bump.sh:105`). So the bump's `die "commit rejected — the edits are staged"` path is not reachable through the new gate.

A bump run offline, or with the `claude` CLI logged out, now fails preflight where it used to pass. That is the intended shape — the sweep is the check the brief asks for — but it is a new way for a release to stop, and it stops before anything is written or committed.
