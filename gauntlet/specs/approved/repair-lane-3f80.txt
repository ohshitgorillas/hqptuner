## Public entry points

```
python3 scripts/excision-diff.py --spec <block path> --base <commit> --head <commit>
python3 scripts/excision-diff.py --self-test
```

All three flags required. Verdicts print one per line to stdout, in this order: one excision verdict per block line in spec order, then one landing verdict per line carrying `as:`, then one `UNNAMED` per changed file under `tests/` that no line names. Exit status 0 when every printed line starts `OK `, else 1. `git` is run from the working directory, so the caller's cwd is the repository.
