public entry points

The planned public surface of `hqptuner/engine/junkadvisor.py`, imported as `from hqptuner.engine import junkadvisor`. Signatures and docstrings only. `Any` is `typing.Any`.

class SpurHolder:
    """The bins a spur verdict is standing on, held across the windows of one track.

    Frequencies rather than bin indices, so a samplerate change re-grids without carrying stale
    indices into the new grid; the bins the new grid does not carry are dropped. The holder records
    no level, no window count and no track identity: the caller discards it with the aggregate.
    """

    def __init__(self) -> None: ...

def classify(min_levels_db: list[float] | None, bandwidth: float, *, samplerate: int | None, sdm: bool, holder: SpurHolder | None = None) -> dict[str, Any] | None:
    """Return the signature this spectrum carries, or None when there is nothing to say.

    Where more than one rule fires, the lowest corner is the verdict: it treats every signature the others name.
    A caller passing no holder reads the window in front of it alone, which is the state of a track that has just
    started; a caller passing one across successive calls carries the spur hold between them.
    """

def verdicts(min_levels_db: list[float] | None, bandwidth: float, *, samplerate: int | None, sdm: bool, holder: SpurHolder | None = None) -> list[dict[str, Any]]:
    """Return one verdict per rule this spectrum fires, in cliff, spur, ramp order."""

def eligible(samplerate: int | None, bandwidth: float, bins: int, *, sdm: bool) -> bool:
    """Whether a spectrum carries enough bins and HF bandwidth for any rule here to read it."""

def treats(verdict: dict[str, Any], junk_filter: str | None, filter_name: str | None) -> bool:
    """Whether the engine's current settings already treat the verdict's signature."""

def treated(junk_filter: str | None, recommended: str) -> bool:
    """Whether the engaged junk filter already treats the detected signature."""

def hz(i: int, bins: int, bandwidth: float) -> float:
    """Centre frequency of bin ``i`` on a grid of ``bins`` bins spanning 0 Hz to ``bandwidth``."""

NO_FILTER = "none"

What a verdict value is. A verdict is a dict. Its `"filter"` key carries the corner as one of the strings `"20k"`, `"30k"`, `"40k"`, `"50k"`, and that string is what every expected outcome above names. It also carries `"reason"`, a sentence of user-facing copy, and `"ceiling_khz"`, a float; a spur verdict carries `"families"` as well, a list of filter-name prefixes. "nothing" in an expected outcome is `classify` returning None, and the corresponding `verdicts` return is the empty list.
