    answer fields, all of them wire identifiers:
      matched    — one object per hit: { group, name, matched_as, entry }
                   group is "tonal", "spatial" or "consistency"; name is the entry's
                   canonical key; matched_as is the name the job's term hit;
                   entry is the stored entry verbatim, carrying its own `senses`
      index      — array of lookup names; every declared name on a miss, [] on a hit
      conflicts  — the `_meta.conflict_pairs` rows naming a matched term, verbatim
      rules      — { direction_convention, named_quality_field, polysemy }
