class SpectralAggregate:
    """Per-track per-bin minimum power spectrum, in two lengths.

    The minimum is kept block-wise: each BLOCK_SECONDS of coverage folds into
    one per-bin-min array, and the deque holds the last WINDOW_BLOCKS of them.
    ``min_db`` reads whatever blocks there are, so it answers from the first
    non-silent frame onward; ``window_min_db`` answers only once WINDOW_BLOCKS
    full blocks have been earned, which is the spur rule's persistence proof.
    Silent frames never touch the minimum (they carry no tone either), and a
    block that saw only silence is dropped rather than pushed.
    """

        """Per-bin minimum (dB) over every block held, or None before the first non-silent frame is folded in.

        Bounded rather than monotone: the deque keeps the last WINDOW_BLOCKS blocks, so the curve spans the trailing
        window however long the track runs and does not deepen without limit as it plays. Empty bins floor at -200.

wire and protocol facts:

- The metering stream is a separate binary TCP stream on port 4322, streamed unconditionally on bare accept, one frame per transform hop, ~43 frames/s at 44.1k (docs/protocol.md:287-291, §7, verified live 2026-07-28).
- Header is 32 bytes little-endian: `u32 version`, `u32 channels`, `u32 xformLength` (spectrum bins, N/2+1, observed 1025), `u32 transformBits`, `f32 bandwidth` (Nyquist, Hz), `f32 transformTime` (s, = hop/rate), `f32 gain`, `u32 reserved` (docs/protocol.md:292).
- Per channel the body carries `f32 peakMax, peak, rms, rmsMax` then `2 × xformLength` f32 transform values as two consecutive halves, reals then imaginaries, not interleaved; bin `k` magnitude is `hypot(a[k], b[k])` and bin `k` sits at `k · bandwidth / (xformLength − 1)` Hz (docs/protocol.md:293). `bandwidth` is therefore the source Nyquist, and a spectrum's bin count and bandwidth come from the frame, never from the engine's configured output rate.
- The reader holds the 4322 connection only while `State` reports playing (state 2) and closes it otherwise (docs/protocol.md:297), so an aggregate's coverage accrues in playing time, not wall time.
