## Wire and protocol facts

- The 8088 configuration lane needs authentication on every page; the 4321 control lane needs none, so a daemon that refuses the password stays reachable throughout (`docs/architecture.md:40`, `tests/api/test_credentials_rejected.py:1-13`, wire verified on 6.0.4).
- An install with no management credentials has no 8088 lane at all, so `ready` never turns true and the pill reads Unreachable (`docs/architecture.md:40`).
- Saving a connection drops HQPTuner's own control lane deliberately, and the poll loop re-dials at 1.0 s, backing off to 5.0 s once in alarm (`docs/architecture.md`, section 3; `hqptuner/core/manager.py:44-45`).
- HQPlayer's management credentials are set with `hqplayerd -u <username> <password>` or on the daemon's own page at port 8088 (`hqplayerd-readme.txt`).
- The Docker host alias this deployment provides is `host.docker.internal` (`compose.yaml:26-30`).
