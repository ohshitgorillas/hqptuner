Wire and protocol facts:

- The preset store keeps its layout version in `store.json` beside the preset XMLs; the file this HQPTuner writes reads `{"schema": 1}` (`hqptuner/presets/store/presets.py:32` names the file, `:40` the number). `{"schema": 99}` is a stamp it does not understand. The mode store keeps its own stamp in its own file, and a too-new mode store is a different refusal (409) from a too-new preset store.
- Preset names are the join key between the mode store and the preset store (`docs/architecture.md` §2).
- `docs/architecture.md` §7's Delete bullet (`:120`) is "remove from store, plus `profile/delete` for daemon's mirror"; the daemon half is wrapped in `contextlib.suppress` (`hqptuner/presets/presetlane.py:277-278`), so `POST /api/profile/delete` answers 200 with no daemon reachable. `DELETE /api/preset/{name}` needs credentials (`HttpMgr`) and answers 503 without them; the credential-free delete route is the one the probe used.
- The API error vocabulary is `hqptuner/api/errors.py:22-37`: `not_found` renders 404, `invalid_input` 422, `store_too_new` 409.

Applicable fixtures:
