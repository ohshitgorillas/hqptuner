Behaviors of `.claude/hooks/reviews-lane.py`, PreToolUse. Verdict function `verdict(name, tool_input, payload) -> str | None`: a reason string denies, `None` allows. `payload` is the hook's stdin JSON; `agent_type` is read from it and an absent key is the orchestrator. Paths below are absolute under a repo root `R`; `R/.claude/worktrees/x-spec` is a worktree of it.

1. A `Write`/`Edit`/`NotebookEdit` whose target resolves under `state/reviews/` of a checkout is denied for every caller except `agent_type` `spec-reviewer` or `plan-reviewer`: with no `agent_type`, `R/state/reviews/x.1.txt` is denied; with `agent_type` `caveman:cavecrew-builder`, `R/state/reviews/x.1.txt` is denied; with `agent_type` `test-writer`, `R/.claude/worktrees/x-spec/state/reviews/x.1.txt` is denied; with `agent_type` `spec-reviewer`, `R/state/reviews/x.1.txt` is allowed; with `agent_type` `plan-reviewer`, `R/state/reviews/x.2.txt` is allowed.
   kills: a hook keyed on the path alone, which allows `R/state/reviews/x.1.txt` for every caller; fails at the first input.
   existing: none (`grep -rln "reviews-lane\|reviews_lane\|state/reviews" tests/` finds nothing)
   bite: null stub returns `None` for every input; fails at the first input, `R/state/reviews/x.1.txt` with no `agent_type`.

2. With `agent_type` `spec-reviewer` or `plan-reviewer`, a `Write`/`Edit` whose target is not under `state/reviews/` is denied: `R/hqptuner/core/m.py`, `R/tests/specs/x.txt`, `R/docs/testing.md`, `R/state/abuse/current` and `R/specs/x.txt` are denied with `spec-reviewer`, `R/CLAUDE.md` is denied with `plan-reviewer`.
   kills: a hook that only guards `state/reviews/`, which lets a reviewer write `R/hqptuner/core/m.py`; fails at that input.
   existing: none (same grep)
   bite: null stub fails at `R/hqptuner/core/m.py` with `agent_type` `spec-reviewer`.

3. With `agent_type` `spec-reviewer` or `plan-reviewer`, a `Bash` command that `free_bash.is_free_bash` meters is denied and one it frees is allowed, whatever path it names: `sed -i 's/a/b/' hqptuner/x.py` is denied; `echo x > state/reviews/x.1.txt` is denied; `git commit -m x` is denied; `make check` is allowed; `cat state/reviews/x.1.txt` is allowed; `grep -n READY state/reviews/x.1.txt` is allowed.
   kills: a hook that denies a reviewer's Bash only when it names `state/reviews/`, which allows `sed -i 's/a/b/' hqptuner/x.py`; fails at that input.
   existing: none (same grep)
   bite: null stub fails at `sed -i 's/a/b/' hqptuner/x.py` with `agent_type` `spec-reviewer`.

4. With no `agent_type`, a `Bash` command is denied when `free_bash.is_free_bash` meters it and it names a `state/reviews/` path, and allowed otherwise: `echo x > state/reviews/x.1.txt` is denied; `sed -i 's/a/b/' state/reviews/x.1.txt` is denied; `rm state/reviews/x.1.txt` is denied; `cat state/reviews/x.1.txt` is allowed; `sed -i 's/a/b/' hqptuner/x.py` is allowed; `git commit -m "state/reviews"` is allowed.
   kills: a hook that denies every command naming `state/reviews/`, which denies `cat state/reviews/x.1.txt`; fails at that input.
   existing: none (same grep)
   bite: null stub fails at `echo x > state/reviews/x.1.txt` with no `agent_type`.

Public entry points

- `verdict(name: str, tool_input: dict, payload: dict) -> str | None` in `.claude/hooks/reviews-lane.py`. `name` is the tool name; `tool_input` carries `file_path` for `Write`/`Edit`/`NotebookEdit` (`notebook_path` for `NotebookEdit`) and `command` for `Bash`; `payload` is the full hook stdin object and supplies `cwd` and, for subagents, `agent_type`.
- `free_bash.is_free_bash(cmd: str, note=None) -> bool` in `.claude/hooks/free_bash.py`; read-only commands return `True`.
