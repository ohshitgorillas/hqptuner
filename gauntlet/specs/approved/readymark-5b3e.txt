Wire facts:

- A restore self-restarts the daemon in about 5.6 s (docs/architecture.md:18; docs/protocol.md:69, `POST /restore` "self-restarts the daemon").
- After a restart port 4321 refuses connections for a window, then accepts and answers `GetInfo` at once; there is no accept-then-hang window (docs/protocol.md:21, :80).
- Control API state is memory-only; a restart reverts it to the config file (docs/protocol.md:22).
- The handshake that defines "reachable" is `GetInfo` (tests/support/fake_control.py:334 answers it; one per connection).
